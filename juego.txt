======
RULES
======

( Collapsable Sokoban, de Franklin P. Dyer: empujas una caja; los muros de tu fila y de tu columna dan un paso hacia ti )
[ > Player | Caja ] -> [ > Player | > Caja ]
[ Wall | ... | Player ] -> [ > Wall | ... | Player ]

( Novedades: el CRISTAL huye de ti; la TOPADORA se acerca como un muro y empuja la caja que tenga delante )
[ Cristal | ... | Player ] -> [ < Cristal | ... | Player ]
[ Topadora | ... | Player ] -> [ > Topadora | ... | Player ]
[ > Topadora | Caja ] -> [ > Topadora | > Caja ]

( La caja en su diana se dibuja distinta; solo es adorno )
late [ Crate Target ] -> [ CrateDone Target ]
late [ CrateDone no Target ] -> [ Crate ]
